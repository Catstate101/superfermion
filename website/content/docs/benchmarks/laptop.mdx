The suite is one notebook with four sections over the same Rust binary: stabilizer sampling,
adjoint gradients, density matrices and large-Clifford sampling. Rust lanes use 4-thread
RAYON; competitor lanes run shipped defaults.

## Verdicts

- Stabilizer: strictly beats every lane on 1/6 warm / 1/6 cold rungs; beats every lane that produced data on 5/6 warm / 2/6 cold rungs.
- Clifford: beats every available lane on 5/5 warm / 2/5 cold rungs; Stim stays ahead on cold large-n brick and randcliff.
- Adjoint: cat beats Qulacs on 10/10 rows and sf-ir on 9/10; max |cat − qulacs| = 2.817e-15; FD anchor error 3.904e-11.
- Density matrix (sf-ir): sf/aer = 8q 0.577, 10q 1.238, 12q 1.549 — faster at 8 qubits, slower at 10 and 12.

## Disclosures

- cat Mode::Stab and Mode::Cliff compile to the SAME Pauli-frame tableau (plan.rs) -- stab and clifford sections measure one pipeline in two n-regimes.
- cat Mode::Dm is a documented hold-out (feasibility probe measured a tie with the routed aer path; keep-only-if-win) -- the dm section benches the sf-ir simulate_dm engine through the same binary, never framed as a cat-mode win.
- cat_pf = 4-thread RAYON; competitors at shipped defaults; Rust lanes not yet reachable from the Python package (engines compared, not shipped APIs).
- Per-lane first-call budget 40 s (over = over_budget, unranked); cirq capped n&lt;=64, stabilizer aer capped n&lt;=256 with probe evidence; capped = not_run_capped, never fabricated.
- GHZ rungs must sample only the all-0/all-1 branches (ghz_ok, validated live).
