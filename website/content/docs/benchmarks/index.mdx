evidence, the machine it ran on, and a row-by-row check that the paper's numbers still
match that evidence.

## What is deliberately not comparable

- The three studies keep separate timing contracts: statevector jobs report the primary
  compute stage, execution-mode rungs report ABBA window means, and MPS jobs report their
  own contracts. No cross-study compute total is introduced.
- `Mode::Stab` and `Mode::Cliff` compile to the same Pauli-frame tableau; matching rows at
  equal circuit and qubit count are by construction.
- `Mode::Dm` is a documented hold-out in the cat crate; the density-matrix section measures
  the sf-ir `simulate_dm` engine and is never framed as a cat-mode win.
- cat lanes run 4-thread RAYON; competitor lanes run shipped defaults; cirq is capped at
  n = 64 and stabilizer Aer at n = 256 (`not_run_capped` rows carry no numbers).
- The desktop study is CPU-only ideal statevector work: no GPU, noise or hardware results.
