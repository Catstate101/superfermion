Superfermion's Rust simulation core delivers significant speedups over popular
quantum computing frameworks in specific regimes. Methodology and per-trial
data live in [`notebooks/benchmarks_walkthrough.ipynb`](https://github.com/Catstate101/superfermion/blob/main/notebooks/benchmarks_walkthrough.ipynb)
(identical circuits, 15 trials, medians reported, GC disabled, correctness
gates on fidelity/distributions).

## Simulation Benchmarks

### Stabilizer Simulation

Clifford-only circuits on the word-packed stabilizer backend.

| Circuit | Qubits | Superfermion (stab) | Qiskit Aer (stab) | Speedup |
|---------|--------|---------------------|--------------------|---------|
| Clifford 500 gates | 100 | 3 ms | 15 ms | **5.0x** |
| Clifford 1000 gates | 100 | 6 ms | 28 ms | **4.7x** |
| QEC surface code | 49 | 2 ms | 12 ms | **6.0x** |

### MPS Tensor Network

Weakly entangled circuits (bond dimension 64).

| Circuit | Qubits | Superfermion (MPS) | Qiskit Aer (MPS) | Speedup |
|---------|--------|-------------------|-------------------|---------|
| Heisenberg XXZ | 50 | 45 ms | 960 ms | **21x** |
| Heisenberg XXZ | 100 | 180 ms | 5,900 ms | **33x** |
| GHZ | 200 | 25 ms | — (OOM) | — |

Note: GHZ is the trivially-best case for MPS (bond dimension 2) — it
demonstrates framework overhead, not tensor-network scaling on heavily
entangled workloads.

## Gradient Benchmarks

### Adjoint Differentiation

The adjoint method computes all parameter gradients in one backward pass,
independently of parameter count (Jones & Gacon 2020).

vs PennyLane's end-user `qml.grad` pipeline (hardware-efficient ansatz,
depth 1):

| Circuit | Params | Superfermion (adjoint) | PennyLane (adjoint) | Speedup |
|---------|--------|----------------------|----------------------|---------|
| SU(2) layer, 4 qubits | 8 | 0.1 ms | 80 ms | **~800x** |
| SU(2) layer, 8 qubits | 16 | 0.3 ms | 44 ms | **~137x** |
| SU(2) layer, 12 qubits | 24 | 14 ms | 58 ms | **4x** |
| SU(2) layer, 16 qubits | 32 | 83 ms | 126 ms | **1.5x** |

**Read the trend, not just the big number:** the large speedups at small
qubit counts come from dispatch overhead — a single FFI call vs PennyLane's
full autograd transform. At n ≥ 18, PennyLane's adjoint backend is faster
than ours. The robust claim is *parameter-count-independent* gradient cost:
vs our own parameter-shift, adjoint is 44–198x faster as circuit depth grows.

## Reproducing Benchmarks

```bash
git clone https://github.com/Catstate101/superfermion.git
cd superfermion
pip install -e ".[benchmarks]"
jupyter lab notebooks/benchmarks_walkthrough.ipynb
```

The walkthrough notebook contains the methodology, stored per-trial data,
and live small-scale reproductions when Qiskit/PennyLane are installed
(with graceful fallback to the stored results otherwise).

## Why the Speedup

1. **Rust with Rayon** — statevector simulation parallelized across CPU
   cores with zero GIL contention
2. **No interpreter overhead** — gate application, sampling, and
   expectation values run entirely in Rust; Python calls cross the FFI
   boundary once
3. **faer linear algebra** — pure-Rust BLAS-quality QR for MPS, avoiding
   LAPACK overhead
4. **Word-packed stabilizer** — Clifford tableau operations on packed
   64-bit words, O(n²) time for n qubits
5. **Memory locality** — custom `StatevectorState` struct with
   column-major layout optimized for AVX auto-vectorization
